# FlyCockpit Tap

## How do I install these formulae?

`brew install flycockpit/tap/<formula>`

Or `brew tap flycockpit/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "flycockpit/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
