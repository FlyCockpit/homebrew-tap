# FlyCockpit Homebrew Tap

Homebrew tap for FlyCockpit command-line tools. The initial formula is `wsmp`,
the WS Model Proxy CLI.

## Install `wsmp`

```sh
brew install flycockpit/tap/wsmp
```

Or tap this repository first:

```sh
brew tap flycockpit/tap
brew install wsmp
```

In a `Brewfile`:

```ruby
tap "flycockpit/tap"
brew "wsmp"
```

## Maintenance

`Formula/wsmp.rb` is generated by cargo-dist in
`FlyCockpit/ws-model-proxy` and committed here by that repository's `Release`
workflow. Do not hand-edit the formula unless you are repairing a failed
release.

The source release workflow requires a protected `release` environment with a
`HOMEBREW_TAP_TOKEN` environment secret that has `contents:write` access to this
repository.
